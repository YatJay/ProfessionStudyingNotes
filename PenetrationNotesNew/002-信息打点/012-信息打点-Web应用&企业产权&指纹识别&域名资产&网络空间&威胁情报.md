通过爱企查等工具，可以将目标企业的资产分为以下五个类型：

1. WEB应用
2. APP应用：APP上可能有其他服务、安全问题
3. PC端应用
4. 小程序应用
5. 微信公众号：微信公众号可能存在目标自己的网址、IP地址等信息
6. 其他产品等

我们本章课程内容，就是收集上述信息，从Web应用到微信公众号等，本节讲解Web应用的信息收集

### Web域名资产

对网站域名进行信息收集，可以分为单域名和子域名

#### WEB单域名

1. 备案信息：从备案信息获取域名

| **标签** | **名称**     | **地址**                   |
| -------- | ------------ | -------------------------- |
| 备案信息 | 备案信息查询 | http://www.beianx.cn/      |
| 备案信息 | 备案管理系统 | https://beian.miit.gov.cn/ |

2. 企业产权：即上面提到的，在企业的工商信息如企查查等平台的“知识产权”当中查询

3. 注册域名：从域名注册平台查询域名

| **标签** | **名称**     | **地址**                             |
| -------- | ------------ | ------------------------------------ |
| 注册域名 | 域名注册查询 | https://buy.cloud.tencent.com/domain |

4. 反查解析：通过IP地址反查域名解析

| **标签** | **名称**   | **地址**                  |
| -------- | ---------- | ------------------------- |
| IP反查   | 微步在线   | https://x.threatbook.cn/  |
| IP反查   | IP反查域名 | http://dns.bugscaner.com/ |

#### WEB子域名

1. DNS数据：即通过查询DNS解析历史，定位目标域名或IP

| **标签** | **名称**    | **地址**                 |
| -------- | ----------- | ------------------------ |
| DNS数据  | dnsdumpster | https://dnsdumpster.com/ |

![image-20260105232616053](https://img.yatjay.top/md/20260105232616137.png)

2. 证书查询：对于https网站可以通过证书查询子域名，通过目标证书来寻找其他哪些网站用过这个证书，比如`map.baidu.com`和`www.baidu.com`使用的是同一个证书，这就关联到了子域名

| **标签** | **名称**          | **地址**        |
| -------- | ----------------- | --------------- |
| 证书查询 | CertificateSearch | https://crt.sh/ |

![image-20260105233344473](https://img.yatjay.top/md/20260105233344560.png)
