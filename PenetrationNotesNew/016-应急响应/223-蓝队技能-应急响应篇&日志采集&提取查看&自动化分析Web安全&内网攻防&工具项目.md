#### 日志自动提取

##### 七牛Logkit

1、七牛Logkit：(Windows&Linux&Mac等)

项目地址：https://github.com/qiniu/logkit

其支持下列应用日志提取

- [File](https://github.com/qiniu/logkit/wiki/File-Reader): 读取文件中的日志数据，包括csv格式的文件，kafka-rest日志文件，nginx日志文件等,并支持以grok的方式解析日志。
- [Elasticsearch](https://github.com/qiniu/logkit/wiki/ElasticSearch-Reader): 读取ElasticSearch中的数据。
- [MongoDB](https://github.com/qiniu/logkit/wiki/MongoDB-Reader): 读取MongoDB中的数据。
- [MySQL](https://github.com/qiniu/logkit/wiki/MySQL-Reader): 读取MySQL中的数据。
- [MicroSoft SQL Server](https://github.com/qiniu/logkit/wiki/MicroSoft-SQL-Server-Reader): 读取Microsoft SQL Server中的数据。
- [Postgre SQL](https://github.com/qiniu/logkit/wiki/PostgreSQL-Reader): 读取 PostgreSQL 中的数据。
- [Kafka](https://github.com/qiniu/logkit/wiki/Kafka-Reader): 读取Kafka中的数据。
- [Redis](https://github.com/qiniu/logkit/wiki/Redis-Reader): 读取Redis中的数据。
- [Socket](https://github.com/qiniu/logkit/wiki/Socket-Reader): 读取tcp\udp\unixsocket协议中的数据。
- [Http](https://github.com/qiniu/logkit/wiki/Http-Reader): 作为 http 服务端，接受 POST 请求发送过来的数据。
- [Script](https://github.com/qiniu/logkit/wiki/Script-Reader): 支持执行脚本，并获得执行结果中的数据。
- [Snmp](https://github.com/qiniu/logkit/wiki/Snmp-Reader): 主动抓取 Snmp 服务中的数据。

###### 使用方法

在logkit.conf配置好端口号等信息之后，命令行输入`logkit.exe -f logkit.conf`运行，程序会生成一个Web页面，按照配置访问指定端口即可配置

![image-20251013220102146](https://img.yatjay.top/md/20251013220102191.png)

在配置的3000端口访问Web服务，添加日志采集或系统信息采集，即可采集日志信息

![image-20251013220148794](https://img.yatjay.top/md/20251013220148839.png)

如系统采集器可以采集如下等信息，根据提示进行配置，点击运行即可开始采集

![image-20251013220240824](https://img.yatjay.top/md/20251013220240870.png)

工具还支持数据解析与变换比如

- Parsers：针对整体数据的解析，支持包括json、csv、grok等大多数主流日志解析方式。

- Transforms：针对字段做数据变换，支持包括字符串操作、ip扩展等多种数据变换方式。

具体操作见项目页介绍

#### 日志自动分析

##### Web日志自动分析

###### Web - 360星图

1、Web - 360星图：仅支持IIS/Apache/Nginx等中间件日志，对Java中间件支持较少

配置config.conf，主要是配置日志文件路径，如`log_file:E:\蓝队\223\分析、access.1og`，还有其他自定义配置。配置之后，直接打开`start.bat`，会自动分析Web日志

![image-20251013222340312](https://img.yatjay.top/md/20251013222340376.png)

分析结果输出在result目录下，如

![image-20251013222402591](https://img.yatjay.top/md/20251013222402628.png)

结果以HTML文档形式输出，打开后如下图所示，会展示攻击IP分布、恶意IP列表、扫描行为、疑似漏洞利用等信息

![image-20251013222425223](https://img.yatjay.top/md/20251013222425304.png)

该工具缺陷是仅支持常规中间件日志，不支持Java中间件日志

###### Web - GoAccess

2、Web - GoAccess：任何自定义日志格式字符串，仅做网站访问流量、访问速度、访问地区等记录，安全方面涉及少，不是用来分析攻击行为的）

https://github.com/allinurl/goaccess

使用手册：

https://goaccess.io/man

输出报告：

goaccess -f /home/wwwlogs/access.log --log-format=COMBINED > /root/aa.html

实时监控：

goaccess -f /home/wwwlogs/access.log --log-format=COMBINED --real-time-html > /home/wwwroot/default/x.html

2、可视化解析Windows登录日志：

chainsaw.exe hunt output/ -s sigma/ --mapping mappings/sigma-event-logs-all.yml -r rules/ --csv --output results
